[#eventing-examples]
= Eventing Examples

== General

This annex is informative.
It contains examples for the events defined in Clause xref:eventing.adoc[Eventing] in both presentations.

All examples use the following objects:

.Objects used in the examples
[%autowidth,width="100%",cols="30%,70%",options="header",]
|===
|Object |Identification
|Base URL of the producer |`\https://aas.example.com`
|Asset Administration Shell |`\https://example.com/ids/aas/7600_5912_3951_6917`
|Asset |`\https://example.com/ids/asset/7600_5912_3951_6917`
|Submodel |`\https://example.com/ids/sm/4210_0802_6152_5421` with semanticId `\https://example.com/semantics/OperationalData/1/0`, base64url-encoded `aHR0cHM6Ly9leGFtcGxlLmNvbS9pZHMvc20vNDIxMF8wODAyXzYxNTJfNTQyMQ`
|Concept Description |`\https://example.com/ids/cd/temperature`
|===

Identical parts of the Regular and Compact presentation of the same event are repeated to keep every example complete.
